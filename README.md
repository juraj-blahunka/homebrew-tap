# juraj-blahunka/tap

Homebrew formulae by Juraj Blahunka.

| Formula | Description |
| --- | --- |
| [simctlhouse](https://github.com/juraj-blahunka/simctlhouse) | Lease iOS simulators to parallel coding agents |

## Install

```sh
brew install juraj-blahunka/tap/simctlhouse
simctlhouse skill install   # once, to link the agent skill into your coding agents
```

Upgrade with `brew upgrade simctlhouse`.
Before uninstalling, run `simctlhouse skill uninstall`, then `brew uninstall simctlhouse`.

## How the formulae are updated

Each formula is published by its project's release process, which builds a signed and notarized binary, attaches it to a GitHub release, and commits the matching formula here.
Report problems with a tool in its own repository; this repository only holds the formulae.
